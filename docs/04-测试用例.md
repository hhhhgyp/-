## 0. 执行约定

### 0.1 基础信息

| 项 | 值 |
|---|---|
| Base URL | `http://127.0.0.1:8138/api/v1` |
| 认证头 | `Authorization: Bearer <access_token>` |
| 内容类型 | `Content-Type: application/json` |
| 时间格式 | ISO 8601，如 `2026-10-20T10:00:00`（脚本用 `datetime.isoformat()`） |
| 时间基准 | `D0` = 数据库 `CURDATE()`；`D0+1 10:00` = 该日 10:00:00 |
| 主账号 | `admin`（ADMIN）、`user01` / `user02`（USER），口令 `Demo@123456` |
| 幂等键 | `tst-<模块>-<序号>-<毫秒时间戳>` |
| 判定 | 状态码 + `code` + 关键字段 + 数据库，四项一致才算通过 |

### 0.3 常用造数 SQL（仅用于构造前置状态，用后必须恢复）

```sql
-- 向上取整到下一个 30 分钟（用于 5 分钟提前量、7 天窗口等边界）
SELECT DATE_ADD(
         DATE_FORMAT(DATE_ADD(NOW(), INTERVAL 5 MINUTE), '%Y-%m-%d %H:%i:00'),
         INTERVAL (30 - MINUTE(DATE_ADD(NOW(), INTERVAL 5 MINUTE)) % 30) % 30 MINUTE
       ) AS next_aligned;

-- 把订单时间整体前移，用于构造"已过签到截止""已逾期"
UPDATE reservations
SET start_time = DATE_SUB(NOW(), INTERVAL 90 MINUTE),
    end_time   = DATE_SUB(NOW(), INTERVAL 30 MINUTE),
    checkin_deadline = DATE_SUB(NOW(), INTERVAL 60 MINUTE)
WHERE order_no = '<order_no>';

-- 构造"恰好到达边界"的签到窗口（earliest = NOW()）
UPDATE reservations
SET start_time = DATE_ADD(NOW(), INTERVAL 15 MINUTE),
    end_time   = DATE_ADD(NOW(), INTERVAL 45 MINUTE),
    checkin_deadline = DATE_ADD(NOW(), INTERVAL 45 MINUTE)
WHERE order_no = '<order_no>';

-- 禁用/恢复账号
UPDATE users SET status = 'DISABLED' WHERE username = 'user02';
UPDATE users SET status = 'ACTIVE'   WHERE username = 'user02';
```

> 用 SQL 改时间后，`reservation_slots` 仍是旧时间，会破坏 C-01/C-10。**造数后必须同步更新或删除 slots**，或在用例结束按 §5.5 清理。仅任务类用例可只改订单（任务不读 slots）。
